## О проекте

**SCity** — это Discord-бот, созданный для того, чтобы сделать серверы комфортными, организованными и приятными для общения. Мы берём на себя рутину — модерацию, логи, приветствия, кнопки ролей, тикеты, уровни и статус сервера — чтобы владельцы и администраторы могли заниматься сообществом, а не настройками.

Бот подходит для любых серверов: игровых кланов, тематических сообществ, уютных групп друзей. Каждая функция полностью настраивается.

## Возможности

| Модуль | Что делает |
|---|---|
| 🛡️ **Модерация** | Авто-модерация спама, ссылок, рекламы, упоминаний, капса и повторяющихся сообщений. Настраиваемые наказания: warn, mute, kick, ban, выдача роли. |
| 📋 **Логирование** | Полные логи сервера: подключения к войсу, смена ролей, удаление и редактирование сообщений. Все события в одном канале. |
| 🎫 **Тикеты** | Настраиваемые формы с вопросами, ролями и целевой категорией. Пользователь нажимает кнопку — создаётся приватный канал. |
| 📊 **Статус сервера** | Живые статус-каналы с количеством участников, онлайном и кастомными названиями. |
| ✨ **Конструктор эмбедов** | Красивые сообщения с заголовками, подзаголовками, разделами и своим текстом. |
| 👋 **Приветствие и прощание** | Сообщения в каналах и ЛС с количеством участников, аватарами, информацией об инвайте и картинками. |
| 📈 **Уровни** | Уровни за сообщения и активность в войсе. Награды ролями — на всём сервере и в отдельных каналах. |
| 🎭 **Кнопки ролей** | Самостоятельная выдача ролей через кнопки с эмодзи. |
| 🔊 **Голос и саундборд** | Заход в голосовые каналы, воспроизведение звуков, управление аудио. |
| 📨 **Рассылки** | Отправка кастомных сообщений сразу в несколько каналов. |
| 🔗 **Трекинг инвайтов** | Кто пригласил каждого участника, сколько у кого инвайтов и сколько удержано. |
| ⚙️ **Контроль доступа** | Детальные права: кто может пользоваться ботом и какие команды доступны. |
| Настроить приветствие участнику в личные сообщения |
