# Политика конфиденциальности

**Последнее обновление:** [12 ноября 2026]

## 1. Какие данные мы собираем
Наш бот может получать и обрабатывать следующие данные, необходимые для работы функций:
- **Идентификаторы Discord (ID):** ID пользователя, ID сервера, ID канала (для сохранения настроек сервера или прогресса).
- **Содержимое сообщений:** Только если это необходимо для работы конкретной команды (например, для команд модерации или игры). Мы не читаем личные сообщения.
- **Метаданные:** Время отправки команд, использование функций.

## 2. Как мы используем данные
- Для обеспечения работы основных функций бота (например, ответов на команды).
- Для устранения неполадок и улучшения работы бота.
- Мы **не продаем** и **не передаем** твои данные третьим лицам.

## 3. Хранение и удаление данных
- Данные хранятся на защищенных серверах.
- Ты можешь запросить удаление своих данных, связавшись с нами в лс [s1ivker]
- Удаление бота с сервера обычно приводит к удалению связанных с сервером настроек.

## 4. Контакты
По вопросам конфиденциальности обращайся: [s1ivker]
