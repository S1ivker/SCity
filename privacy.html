Privacy Policy

Last updated: November 12, 2026

1. Introduction

This Privacy Policy describes what data the SCity Discord bot (the "Bot") collects, how it is used, stored, and protected. By using the Bot, the User agrees to the terms of this Policy.

2. Data We Collect

To ensure the Bot's operation, we may collect and process the following categories of data:

  • Discord identifiers: user ID, server (guild) ID, channel and role IDs — required for commands and permissions;
  • Server data: server name, Bot settings, module configuration (moderation, tickets, server status);
  • Message content: only to the extent necessary for moderation features (e.g. logging deleted messages), and only when the relevant module is enabled by the server administrator;
  • Ticket data: text of requests submitted through the ticket system, for handling user inquiries;
  • Technical data: error logs and service logs that do not contain personal data in plain text.

We do not collect passwords, payment data, private messages unrelated to Bot commands, or other excessive information.

3. Purposes of Processing

  • ensuring the Bot's functionality (moderation, tickets, server status, etc.);
  • saving server settings and user preferences;
  • processing requests via the ticket system;
  • detecting and preventing abuse;
  • improving the Bot's quality and fixing errors.

4. Legal Basis

Data processing is based on the User's consent (adding the Bot to a server and using its commands) and the Administration's legitimate interest in ensuring the Bot's operability and security.

5. Storage and Protection

Data is stored on secure servers accessible only to authorized representatives of the Administration. We apply reasonable technical and organizational measures to protect data from unauthorized access, modification, or destruction. Data retention periods are determined by the necessity of their use for the purposes specified in Section 3. Data that is no longer relevant is deleted or anonymized.

6. Third-Party Sharing

We do not sell or share User data with third parties, except:

  • as required by law;
  • data transfer via the official Discord API necessary for the Bot's operation;
  • use of infrastructure services (hosting, database) that process data solely on our behalf and have no right to use it for other purposes.

7. User Rights

The User has the right to:

  • request information about what data of theirs is processed;
  • request deletion of their data;
  • withdraw consent to processing by removing the Bot from the server and contacting support.

To exercise these rights, contact us using the details in Section 10.

8. Minors

The Bot is not intended for persons under the minimum age set by the Discord Terms of Service. We do not knowingly collect data from such persons. If such data is received, it will be deleted upon request.

9. Changes to This Policy

The Administration may change this Policy. The current version is always available on this page. Continued use of the Bot after changes constitutes acceptance of the new version.

10. Contact

For questions regarding data processing and this Policy, contact us:

  • Developer (Direct Message)

Политика конфиденциальности

Последнее обновление: 12 ноября 2026 г.

1. Введение

Настоящая Политика конфиденциальности описывает, какие данные собирает Discord-бот SCity (далее — «Бот»), как они используются, хранятся и защищаются. Используя Бота, Пользователь соглашается с условиями настоящей Политики.

2. Какие данные мы собираем

Для обеспечения работы Бота мы можем собирать и обрабатывать следующие категории данных:

  • Идентификаторы Discord: ID пользователя, ID сервера (гильдии), ID каналов и ролей — необходимы для работы команд и системы прав;
  • Данные сервера: название сервера, настройки Бота, конфигурация модулей (модерация, тикеты, статус сервера);
  • Содержимое сообщений: только в объёме, необходимом для работы функций модерации (например, логирование удалённых сообщений), при условии, что соответствующий модуль включён Администратором сервера;
  • Данные тикетов: текст обращений, созданных через систему тикетов, для обработки запросов пользователей;
  • Технические данные: журналы ошибок и служебные логи, не содержащие персональных данных в открытом виде.

Мы не собираем пароли, платёжные данные, содержимое личных сообщений, не связанных с командами Бота, и иную избыточную информацию.

3. Цели обработки данных

  • обеспечение работы функций Бота (модерация, тикеты, статус сервера и др.);
  • сохранение настроек сервера и пользовательских предпочтений;
  • обработка обращений через систему тикетов;
  • выявление и предотвращение злоупотреблений;
  • улучшение качества работы Бота и устранение ошибок.

4. Правовые основания

Обработка данных осуществляется на основании согласия Пользователя (добавление Бота на сервер и использование его команд), а также законного интереса Администрации в обеспечении работоспособности и безопасности Бота.

5. Хранение и защита данных

Данные хранятся на защищённых серверах, доступ к которым имеют только уполномоченные представители Администрации. Мы применяем разумные технические и организационные меры для защиты данных от несанкционированного доступа, изменения или уничтожения. Срок хранения данных определяется необходимостью их использования для целей, указанных в разделе 3. Данные, утратившие актуальность, удаляются или обезличиваются.

6. Передача данных третьим лицам

Мы не продаём и не передаём данные Пользователей третьим лицам, за исключением:

  • случаев, предусмотренных законодательством;
  • передачи данных через официальный Discord API, необходимой для функционирования Бота;
  • использования инфраструктурных сервисов (хостинг, база данных), которые обрабатывают данные исключительно по нашему поручению и не имеют права использовать их в иных целях.

7. Права пользователей

Пользователь имеет право:

  • запросить информацию о том, какие его данные обрабатываются;
  • потребовать удаления своих данных;
  • отозвать согласие на обработку, удалив Бота с сервера и обратившись в поддержку.

Для реализации этих прав обратитесь по контактам из раздела 10.

8. Данные несовершеннолетних

Бот не предназначен для лиц младше минимального возраста, установленного Условиями использования Discord. Мы не собираем сознательно данные таких лиц. Если такие данные были получены, они будут удалены по запросу.

9. Изменения политики

Администрация вправе изменять настоящую Политику. Актуальная версия всегда доступна на этой странице. Продолжение использования Бота после изменений означает согласие с новой редакцией.
